# SNHU CS-340: Client/Server Development

## Overview
This repository contains coursework and projects completed for CS-340 at Southern New Hampshire University. The focus of this course is on client/server development using Python, MongoDB, and web-based data visualization tools.

## Technologies Used
- Python
- MongoDB
- PyMongo
- Jupyter Notebook
- Dash (Plotly)

## Projects

### CRUD Module
- Developed a Python-based CRUD (Create, Read, Update, Delete) module for interacting with a MongoDB database.
- Implemented secure database connections and query handling.

### Dashboard Application
- Built an interactive dashboard using Dash and Plotly.
- Integrated MongoDB data with dynamic visualizations.
- Implemented filtering and geolocation features.

## Skills Demonstrated
- Database design and NoSQL data management
- Client/server architecture concepts
- Data visualization and dashboard development
- Python application development
